# 元素ガチャ

元素118種をカードとして集めながら覚える学習ゲームです。
新しい元素はガチャで入手し、間隔反復（ライトナー方式）で復習して定着させます。

ランダム性は「報酬（ガチャ）」にだけ置き、「どの問題を出すか」は間隔反復で決めています。

- スマホのホーム画面に追加でき、オフラインでも動きます（PWA）
- 進行データはその端末のブラウザの中に保存されます。サーバーには何も送りません

---

## 遊び方

### 1. ガチャで元素を手に入れる

- 最初に石を100個持っています（10連が1回引けます）
- 無料ガチャは **6時間ごとに1回**（0時・6時・12時・18時に回復。1日最大4回）
- ほかに「1回＝石8個」「10連＝石80個」で引けます
- 排出率は N 55％ / R 30％ / SR 12％ / SSR 3％
- SR以上が出ないまま29回続くと、**30回目はSR以上が確定**します（天井）
- 同じレア度の中では、まだ持っていない元素が優先して出ます
- 手に入れた元素は、その場で復習の対象になります

| レア度 | 目安 | 枚数 |
|---|---|---|
| N | 身近な元素（水素・酸素・鉄・金など） | 20 |
| R | 主要な元素（フッ素・チタン・白金・鉛など） | 25 |
| SR | 遷移金属・ランタノイドの多く、なじみの薄い典型元素 | 43 |
| SSR | アクチノイドと超重元素 | 30 |

### 2. 復習する（4択）

- 復習の期限が来たカード（と、下の「当日の確認」の時刻が来たカード）だけが出題されます
- 問題の形式は5種類：記号→名前、名前→記号、分類当て、用途→元素、原子番号→名前
  - はじめは記号と名前の問題だけ。段階が上がると難しい形式が加わります
- 誤答の選択肢は、同じ分類や近い原子番号の元素から選ばれます
- まちがえたときは、選んだ元素と正解を並べて違いを表示します。周期表で近いほど「おしい！」が強くなります

### 3. 段階と復習の間隔

カードには段階（0〜5）があり、正解すると1つ上がり、不正解だと段階1に戻ります。

| 段階 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 次の復習まで | 当日 | 1日 | 3日 | 7日 | 14日 | 30日 |
| 正解でもらえる石 | 1 | 2 | 3 | 5 | 8 | 12 |

- 段階5に着いたカードは「マスター」になります
- **ガチャ石は、期限の来たカードに正解したときだけ**もらえます。長い間隔を越えて思い出せたほど多くもらえます
- 日付は端末の時刻の0時で切り替わります

### 4. 当日の確認（1日に何度も遊べる仕組み）

- 新しく手に入れたカードの最初の問題と、復習で**まちがえたカード**は、同じ日のうちに **10分後 → 1時間後** にもう一度「確認」として出題されます
- 確認に正解すると **石1個**。2回とも正解すれば、その日の確認は完了です
- 確認でまちがえたら、同じ確認を10分後にやり直します（石はもらえません）
- 確認では段階は変わりません。日付が変わると、やり残した確認は消えます（罰はありません）
- ホームに「次の確認：あと8分」のように出るので、少し時間をおいてまた開いてください

### 5. 自主練習

- 期限前のカードは「自主練習」で解けます。石は出ず、段階も変わりません
- そのかわり、正解すると **かけら1個**（1日5個まで）がもらえます
- 今日の確認が残っているカードは、自主練習には出ません

### 6. かけら

- すでに持っている元素がガチャで出ると「かけら」に変わります（N 1 / R 2 / SR 3 / SSR 5個）。自主練習でももらえます
- かけら20個で、好きな未所持元素1枚と交換できます（ガチャ画面の「かけらで好きな元素と交換」から）

### 7. カードの見た目

- カードには、元素記号・原子番号・名前・分類と、電子殻の図（ボーア模型風）が描かれています。色は分類ごとに違います
- 枠はレア度で変わります：N＝灰色、R＝銀青の二重線、SR＝金枠と四隅の飾り、SSR＝虹色に回る枠
- 習熟度（段階）が上がると枠が進化します：段階2〜3＝銀の内枠、段階4＝金の内枠、段階5＝**マスター枠**（MASTER の帯つき）
- マスター後にまちがえて段階が下がると枠も戻りますが、「一度マスターした」印（★）が残ります

### 8. ガチャの演出

- 光の色で、その回にいちばん高いレア度がわかります：白＝N、青＝R、金＝SR、虹色＝SSR
- SR以上のときは、白い光が途中で色に変わります
- 画面をタップすると演出を飛ばせます（端末で「視差効果を減らす／アニメーションを減らす」を設定していると演出は出ません）

### 9. 図鑑

- 周期表の並びで全118種を表示します。未所持の元素はシルエット（原子番号だけ）です
- 所持している元素は、枠の色＝レア度、塗りの濃さ＝習熟度で色分けされます。★はマスター
- 「分類」に切り替えると、分類ごとの色で周期表を見られます
- マスをタップすると、カードと学習の進み具合（段階・次の復習日・正解数）が見られます

### 10. 記録

- 期限の来た復習の正答率を、30日分のグラフで表示します（点をタップすると数値、「数値で見る」で表）
- 段階ごとのカードの枚数、連続で復習した日数、これまでの合計（当日の確認・自主練習を含む）も見られます

## スマホで遊ぶ（ホーム画面に追加）

公開したページ（下の「公開の手順」を参照）をスマホで開き、ホーム画面に追加します。

- **iPhone（Safari）**：画面下の共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

ホーム画面のアイコンから開くと、アプリのように全画面で動き、電波がなくても遊べます。

> iPhone の Safari では、ホーム画面に追加せずに使っていると、しばらく開かなかったときにブラウザが保存データを消すことがあります。**ホーム画面に追加して使う**のと、**ときどきバックアップを書き出す**のがおすすめです。

---

## 進行データの保存・バックアップ・リセット

「設定」画面（ホーム右上の ⚙、または記録画面の下）から次のことができます。

- **バックアップを書き出す**：進行データを JSON ファイルとして保存します（例：`genso-gacha-backup-2026-09-26.json`）
- **バックアップを読み込む**：書き出したファイルを読み込んで、進行データを元に戻します。機種変更のときにも使えます
- **すべてリセット**：カード・石・記録をすべて消して、はじめからにします（2回確認があります）

## 公開の手順（GitHub Pages）

このリポジトリは、`main` ブランチに変更が入ると自動でテスト・ビルドして GitHub Pages に公開するよう設定してあります（`.github/workflows/deploy.yml`）。

### 最初の1回だけ行う設定

1. GitHub でこのリポジトリを開く
2. 上のメニューの **Settings** → 左側の **Pages** を開く
3. 「Build and deployment」の **Source** を **GitHub Actions** にする

### 公開する

1. プルリクエストを `main` にマージする
2. リポジトリの **Actions** タブで「GitHub Pages に公開」が緑のチェックになるのを待つ（数分）
3. 次のアドレスを開く：**https://konja9.github.io/genso-gacha/**

公開のたびに、アプリを次に開いたとき自動で新しい版に入れ替わります。

> リポジトリ名を変えた場合は、`vite.config.ts` の `BASE` も同じ名前に変えてください。

## スマホ実機での動作確認の手順

公開後、スマホで次の順に確かめてください。（5の「当日の確認」で10分待つ以外は、1〜2分で終わります）

1. **開く**：スマホのブラウザ（iPhone は Safari、Android は Chrome）で https://konja9.github.io/genso-gacha/ を開く。ホーム画面が表示されればOK
2. **ホーム画面に追加**：上の「スマホで遊ぶ」の手順で追加し、ホーム画面のアイコンから開き直す。上下にブラウザのアドレスバーが出ず、全画面で開けばOK
3. **ガチャ**：「ガチャへ」→「10連で引く」。光の演出のあと、カードが10枚並べばOK。画面をタップして演出を飛ばせるかも試す
4. **復習**：「さっそく覚える」→ 何問か答える。1問はわざとまちがえて、比較の表と小さな周期表が出ればOK。結果画面に「次の確認：あと10分」と出ればOK
5. **当日の確認**：10分ほどたってからアプリを開き、ホームの「いま解ける問題」が増えていて、確認の問題（「当日の確認 1/2」の札つき）に答えると石が1個増えればOK
6. **保存**：アプリを完全に閉じて（アプリ切り替え画面で上にスワイプ）開き直す。石の数と所持数が残っていればOK
7. **オフライン**：機内モードにしてアプリを開き直す。いつもどおり表示され、復習やガチャができればOK。確認後に機内モードを戻す
8. **図鑑・記録**：図鑑で入手した元素が色つきで並び、マスをタップすると詳しく見られること、記録に今日の正答率が出ることを確かめる
9. **バックアップ**：設定 →「バックアップを書き出す」。iPhone は「ファイル」アプリ、Android は「ダウンロード」フォルダに JSON ファイルが保存されればOK

うまくいかないとき：
- **古い画面のまま**：新しい版を公開した直後は、アプリを一度閉じて開き直すと入れ替わります（2回開き直すと確実です）
- **ホーム画面に追加が出ない（Android）**：Chrome の「︙」メニューに「アプリをインストール」または「ホーム画面に追加」があります
- **パソコンの画面で確かめたい**：Chrome で開き、F12 → 左上のスマホのアイコンでスマホ表示にできます

## 手元のパソコンで動かす（開発者向け）

[Node.js](https://nodejs.org/) の 22 以上が必要です。

```sh
npm install        # 最初に1回だけ。必要な道具をダウンロードする
npm run dev        # 開発用サーバーを起動 → http://localhost:5173/genso-gacha/ を開く
```

そのほかのコマンド：

| コマンド | すること |
|---|---|
| `npm test` | 間隔反復・ガチャ確率・出題・記録の集計などのテストを実行する |
| `npm run validate` | 元素データとレア度表に誤りがないか確かめる |
| `npm run build` | 公開用のファイルを `dist/` に作る |
| `npm run preview` | 作った公開用ファイルを手元で確かめる（オフライン動作もここで試せる） |
| `npm run check` | validate・test・build をまとめて行う |

## 調整のしかた

### 数値を変える（排出率・天井・石・かけら・復習間隔・当日の確認・無料ガチャの時刻など）

すべて **`src/config.ts`** の1か所にまとめてあります。変えたら `npm test` で確かめてください。

### レア度を入れ替える

**`data/rarity.json`** で、原子番号を別のレア度の一覧へ移します。全118種がちょうど1回ずつ入っている必要があります（`npm run validate` で確かめられます）。

### 元素データを直す

**`data/elements.json`** を編集し、`npm run validate` を実行します。次のことを自動で確かめます。

- 118件そろっているか、原子番号と記号に重複がないか
- 電子殻ごとの電子数の合計が原子番号と一致するか
- 分類・状態が決められた一覧にあるか
- 用途の文が1文で、答えになる元素名を含んでいないか、ほかの元素と同じ文でないか

## 元素データについて

- 項目：原子番号、記号、日本語名、英語名、周期、族、分類、常温での状態、電子殻ごとの電子数、身近な用途（1文）
- 用途の文は、事実をもとに独自に書いたものです
- 分類は10種類（アルカリ金属、アルカリ土類金属、遷移金属、典型金属、半金属、非金属、ハロゲン、貴ガス、ランタノイド、アクチノイド）
  - 12族は遷移金属、ランタノイドとアクチノイドは3族として扱っています（高校の新しい教科書に合わせています）
- 超重元素（104〜118番）は性質が確かめられていないため、分類は族から予測したもの、状態は「不明」としています。用途がないため、用途の欄には名前の由来を書いています
- 100番以降も、まとまった量が作られたことがないため状態を「不明」としています

## ファイル構成

```
data/elements.json        118元素のデータ
data/rarity.json          レア度の振り分け
scripts/validate-data.ts  データ検証（npm run validate）
src/config.ts             ★調整用の数値
src/core/                 画面に依存しない計算（間隔反復・ガチャ・出題・報酬・惜しさ・電子殻の図の配置・記録の集計）
src/state/                進行データの保存・バックアップ・ゲームの操作
src/ui/                   画面（ホーム・復習・ガチャ・かけら交換・図鑑・記録・設定）、カード、演出
src/styles/               見た目（CSS）
tests/                    テスト（Vitest）
public/icons/             アプリのアイコン（icon.svg から PNG を作成）
```
